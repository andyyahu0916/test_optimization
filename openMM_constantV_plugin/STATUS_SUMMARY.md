## 致命錯誤: PME 缺失

### 問題描述
`calculateEfKernel` 使用真空求和 `Σ (k·q/r)`, 完全忽略 PME:
- ❌ 無長程倒空間項
- ❌ 無鏡像電荷貢獻
- ❌ 無 Ewald 修正

### 影響
- 週期性系統: 電位錯誤 → 電荷錯誤 → **結果完全無效**
- 真空系統: 可用於測試

### 修正需求
必須使用 OpenMM 的 PME 計算能力，需要：
1. Python 端設定 interaction groups
2. CUDA 端調用 OpenMM PME API
3. 提取每個電極原子的電位

**預計工作量:** 高 (1-2 週)
