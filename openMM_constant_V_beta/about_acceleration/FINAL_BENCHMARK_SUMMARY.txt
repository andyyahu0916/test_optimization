為什麼 Cython 這麼快？

Original (Python loop):
  • Python interpreter overhead
  • Dynamic typing checks
  • Object creation/destruction
  • GIL (Global Interpreter Lock)
  
Optimized (NumPy):
  • Vectorized C operations
  • Batch processing
  • Reduced Python calls
  • Still some overhead for array views

Cython (C-compiled):
  • Pure C loop (compiled)
  • Static typing
  • No Python overhead
  • Compiler optimizations (loop unrolling, etc.)
  • Direct memory access
