🔧 如果遇到問題：
═══════════════════════════════════════════════════════════════════════════

   ⚠️ "Cython module not available"
   → cd lib && python setup.py build_ext --inplace
   
   ⚠️ "Config file not found"  
   → python benchmark_poisson.py -c /path/to/config.ini
   
   ⚠️ OpenMM 錯誤
   → 改用: python benchmark_poisson_minimal.py
