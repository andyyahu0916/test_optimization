# 🔥 Good Taste Benchmark Results

## 測試目標

1. **數值正確性**：驗證 Cython 版本與原始 Python 版本計算結果完全一致
2. **性能穩定性**：測試加速比隨粒子數變化的穩定性

## 測試結果總結

### ✅ 數值正確性

**結論：完全一致**
- Cathode 最大差異: **0.00e+00**
- Anode 最大差異: **0.00e+00**
- 相對誤差: **0.00e+00**

**結論：Cython 版本與原始版本的 Poisson 計算結果完全相同（機器精度）**

---

### 📊 性能測試結果（擴展性測試）

#### 1️⃣ 純計算部分（不含 API 同步）

| 尺寸（原子/電極） | 原始版本 (μs) | Good Taste (μs) | 加速比 |
|------------------|---------------|-----------------|--------|
| 100              | 42.78         | 2.06            | **20.81x** |
| 300              | 141.48        | 3.24            | **43.60x** |
| 500              | 253.65        | 3.77            | **67.32x** |
| 1000             | 609.96        | 5.18            | **117.79x** |
| 2000             | 934.21        | 7.66            | **121.99x** |
| 5000             | 2358.99       | 15.00           | **157.25x** |

**加速比統計：**
- 平均加速比: **88.13x**
- 標準差: 47.87x
- 變異係數: 54.3%

**分析：**
- ✅ **隨著粒子數增加，加速比持續提升**（從 20x → 157x）
- ✅ **Cython 優化在大系統中更有效**（O(n) Python 循環被消除）
- ⚠️ 變異係數較大是因為加速比本身持續增長（這是好事！）

- **平均值**：μs（微秒）
- **標準差**：評估時間波動
- **變異係數**：CV = σ/μ（評估穩定性）
